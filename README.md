## 🌟 Key Highlights & FAANG-Grade Features

1. **Frictionless Onboarding**:
   - Learners enter **only their name** (e.g. *"Aarav Sharma"*) to immediately begin the journey.
   - Saves progress automatically in local storage with smooth resumption.
2. **Video Game Style HUD & Theme Engine**:
   - **Light / Dark Mode Toggle**: Instant switching between Royal Udaipur Midnight and Palace Marble Ivory themes.
   - **Video Game HUD**: Dynamic level titles, animated XP gauge, avatar evolution, and audio controls.
   - **Procedural Synthesizer**: Web Audio API sound effects for steps, clicks, victories, and level-ups (zero external sound file dependencies).
   - **Keyboard Navigation**: `Escape` closes modals, `Space` toggles simulation play/pause, `ArrowRight`/`ArrowLeft` step algorithms forward/back.
3. **10 Landmark Zones & Complete DSA Curriculum**:
   - **Zone 1: SPSU Campus (Bhatewar)** — Arrays, Memory Contiguity & Two-Pointers.
   - **Zone 2: Fateh Sagar Lake & Paal** — Singly, Doubly, Circular Linked Lists & Cycle Detection.
   - **Zone 3: City Palace of Udaipur** — Stacks (LIFO), Monotonic Stack & FIFO Queues.
   - **Zone 4: Saheliyon-ki-Bari** — Recursion, Call Trees & N-Queens Backtracking.
   - **Zone 5: Jag Mandir Island Palace** — Divide & Conquer, Binary Search & Merge/Quick Sort.
   - **Zone 6: Sajjangarh (Monsoon Palace)** — Trees, Binary Search Trees & Inorder Traversals.
   - **Zone 7: Bagore Ki Haveli** — Hash Tables, Collision Resolution & Binary Min-Heaps.
   - **Zone 8: Lake Pichola & Ropeway** — Graph Modeling, BFS, DFS & Dijkstra's Shortest Path.
   - **Zone 9: Kumbhalgarh Fort** — Dynamic Programming (0/1 Knapsack, Coin Change) & Greedy.
   - **Zone 10: SPSU Grand Convocation** — Algorithmic Synthesis (LRU Cache, Tries, Union-Find).
4. **Interactive Visualizer Engine**:
   - Live visual simulation for all 10 algorithms with step-by-step playback, speed control (0.5x, 1x, 2x), and real-time state commentary.
5. **Multi-Language Code Lab**:
   - Complete, verified solutions in **C++**, **Java**, **Python**, and **JavaScript** with one-click copy.
6. **High-Digital Resolution Certificate & Badges — Powered By Kapil**:
   - **Strict Zero-Spillover & Zero-Overlap Guarantee**: Mathematically bounded SVG preview with dynamic font measurement.
   - **Ultra-Crisp 4K Export (3600 × 2400 px, 300 DPI)** rendered to lossless PNG.
   - **Authentic Signatories**: Certified & Authorized by **Kapil** (Lead Architect & DSA Mentor) alongside SPSU Academic Audit and verification seal (NO fake signatories).
   - **11 Royal Udaipur Badges**: Each with custom icons and "Powered By Kapil" attribution.
